# CLAUDE.md

## 项目说明
本目录用于维护个人网站版本 `myresume`，定位为面向 HR / 用人经理的 AI 产品经理作品化介绍页。

## 协作约定
1. 优先在现有 `index.html`、`app.js`、`styles.css` 上直接优化，不重复新建相似页面。
2. 网站文案的事实来源以 `../assets/resume.json` 为准；公开展示口径应与 PDF 简历保持一致，不擅自拔高。
3. `../PDF/resume-v2-pm.pdf` 为当前站内简历入口，调整网站内容时同步检查跳转与口径一致性。
4. 本站依赖 `fetch('../assets/resume.json')` 读取数据，本地调试优先使用静态服务打开，不直接以 `file://` 方式验证。
5. 如需扩展页面模块，优先复用现有 section / card / reveal 结构与蓝色轻量视觉风格。

## 当前目标
1. 梳理 `myresume` 的信息结构与展示逻辑。
2. 在不泄露敏感交付材料的前提下，强化项目亮点、岗位匹配度与联系转化。
3. 为后续 GitHub Pages 部署预留清晰目录与入口结构。
