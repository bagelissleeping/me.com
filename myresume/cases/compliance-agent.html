保险合规审查AI产品｜Workflow / RAG

如何把审查规则变成可复用的流程？

2025-07 至今 · 产品定义与POC推进 · POC／客户试点

主导独立产品定义、审查Workflow与Demo／POC方案，完成核心Prompt迭代，参与客户演示与反馈推进。

1–2小时 → 30分钟内单份材料审查时间
3家以上客户POC演示保险行业客户业务认可
4版核心Prompt迭代围绕准确性、覆盖度与报告可用性

项目背景

保险条款、营销文案等材料依赖人工审查，效率低、标准化不足。基于 ToB 消保系统的 AI 审查需求探索独立产品化，通过 Demo／POC 验证产品方案。

关键判断

将系统能力抽象为独立AI产品，明确客户、场景与产品边界；在规则录入阶段由AI生成结构化审查方案，并保留关键风险分级的人工确认，供后续审查复用。

产品方案

围绕审查方案生成、规则检索匹配、风险定级与复检报告设计多阶段Workflow；Demo阶段以Prompt＋RAG串联关键任务，通过POC和客户试点验证方案。

展开实施细节
  • 产品机会与定义：主导将系统能力抽象为独立 AI Agent 产品，明确目标客户、核心场景、产品边界及 Demo／POC 方案。
  • AI产品方案：围绕审查方案生成、规则检索匹配、风险定级及复检报告设计多阶段 Workflow；Demo 阶段以 Prompt + RAG 串联关键任务。
  • AI生成审查方案：在规则录入阶段结构化输出审查目标、风险定位、风险分级判定规则、判定依据及修改建议，经人工确认关键分级后复用于后续审查，提高规则配置效率与审查一致性。
  • 评测与优化：基于客户条款样本及市场同类材料，围绕审查准确性、覆盖度及报告可用性，独立完成4版核心 Prompt 迭代与测试优化。
  • 客户验证：输出客户演示方案与原型，参与对外沟通及反馈推进，推动项目进入合作推广与客户试点阶段。
